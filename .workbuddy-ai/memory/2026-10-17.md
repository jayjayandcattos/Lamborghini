# 2026-10-17

## Frontend redesign — "three.js example page" direction

Rebuilt the entire UI of the Lamborghini configurator as if it shipped as an official three.js /
R3F example, replacing the dark glassmorphism HUD. User asked for three.js aesthetics + AOS + GSAP.

### Design direction
- Light "paper" theme: `--color-paper #f2f1eb`, `--color-panel #faf9f5`, `--color-ink #12120f`,
  hairline `--color-line #d9d7cd`. Per-model paint drives `--accent`, plus a computed
  `--accent-ink` (HSL lightness capped at 0.45) so small accent type stays readable.
- Type: Archivo (variable width 112%) for display, Instrument Sans for body, JetBrains Mono for
  metadata. `.display`, `.label`, `.num`, `.row` component classes in `src/index.css`.
- Layout: header (54px) / docs sidebar (226px) / viewport / inspector (310px) / status bar (28px).
  Mobile: single scrolling column, sidebar becomes a drawer.

### Architecture
- `App.tsx` = state only (model index, paint, camera view, scene flags, inspector tab, drawer).
- New components: Header, Sidebar, Viewport, Scene, Inspector, CodePanel, StatusBar, Preloader,
  SplitText, Mark, StageDecor. Deleted ShieldLogo.tsx and Atmosphere.tsx.
- `useRenderStats` polls a mutable stats ref so the 3D scene never re-renders for a number.
- Inspector has a live code tab that rewrites itself from state.

### Gotchas worth remembering
- **AOS strips `aos-animate` on re-render** (some rows went invisible after a model switch).
  Fixed by pinning any element that has already revealed itself: an interval sets
  `[data-aos-locked]`, and CSS forces `opacity:1 / transform:none` on it.
- **Never use a per-character `overflow:hidden` mask on a title that can wrap** — the negative
  margin collapses the second line and clips glyphs. SplitText now animates y/opacity with no mask.
- **The old zoom spring (explicit Euler) explodes at large frame deltas** and parked the camera at
  MIN/MAX radius. Replaced with `THREE.MathUtils.damp` and a capped delta (`min(delta, 1/30)`).
- Portrait viewports need a camera pull-back factor (`fit` in CarModel) or the car overflows.
- GLB paint materials are matched by substring: `2020Paint_Material` (aventador),
  `PaintB_Material` (huracan), `Car_Paint_03` (gallardo), `WhiteCar` (urus). Materials are cloned
  per instance before tinting so the cached GLTF asset is never mutated.
- `gl.info.render` is useless here because ContactShadows renders last — triangle/draw-call counts
  are computed from the merged geometries instead.

### Verification
`npx tsc --noEmit` clean, `npm run build` clean. Visual checks done via Playwright at 1440×900 and
390×844 (software WebGL is ~1 FPS, so screenshots need long timeouts).
